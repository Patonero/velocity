# Roadmap

Rough, unpromised, and subject to change. Suggestions welcome via a
[feature request](https://github.com/Patonero/velocity/issues/new?template=feature_request.md).

## Near term

- **Opt-in pre-release channel** - a "pre-release builds" toggle in Settings,
  fed by a nightly build workflow, for users who want changes early
- **winget / Scoop packages** - install and update via the command line

## Later

- **Theme editor** - custom CSS import, an in-app visual editor with live
  preview, and a way to share themes
- **macOS / Linux builds** - the core is Electron; the blockers are
  platform-specific icon extraction and process launching

## Not planned

- Game library scraping / box art / metadata - Velocity launches emulators,
  it isn't a front-end for your ROM collection. Use Playnite or LaunchBox
  if that's what you want.
